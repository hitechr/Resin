# Optional IP Quality

Set `RESIN_IP_QUALITY_ENABLED=true` with a nonempty `RESIN_ADMIN_TOKEN` to enable an admin-only manual IP reputation check in the node detail drawer. The default One IP-compatible endpoint is `https://ip.huzhihui.com/api/ip/health`; set `RESIN_IP_QUALITY_ENDPOINT` to an operator-approved HTTPS endpoint to override it at startup. Confirm provider usage terms and disclosure of egress IPs before enabling the public service in production. A self-hosted One IP still depends on Net.Coffee upstream. Resin does not copy or bundle One IP's AGPL code; it consumes an HTTP contract. See the [One IP Worker](https://github.com/zhihui-hu/one-ip/blob/main/public/worker/ip-health.js) and [license](https://github.com/zhihui-hu/one-ip/blob/main/LICENSE).

The configured provider receives the public egress IP only when an admin clicks **Check IP quality**. Opening the drawer reads local cache only. Successes are kept in a bounded 10,000-IP in-memory LRU, fresh for 24 hours and then shown as stale until evicted; restart or changing the endpoint clears the cache. Unknown scores and flags are not zero or false. The score is third-party IP reputation (higher is better), not node availability or a routing signal. Disabled or unroutable nodes may have only a last observed IP. Provider failures do not alter node health.

Each process admits at most two in-flight lookups and one new request per second; multiple Resin instances do not share a rate budget. The public Worker documents a per-caller GET limit of 180 per 60 seconds, but offers no bulk-use or availability guarantee. Coordinate a shared limit across replicas or use an authorized endpoint. No periodic scan, persistence, or routing policy is included.
